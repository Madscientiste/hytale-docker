Circle color = health check state.

starting: healthy up to HEALTH_STARTUP_MINUTES downloading: always healthy verifying: always healthy running: healthy when the server answers over RCON

New: step 5b. It checks the server options. With VERIFY_WORLDS=true it also checks the worlds, and repairs them with RECOVERY_MODE.

On error. A wrong setting, a failed mod download or a failed world check stops the container. The server is not started.

hy-restart. All steps run again, so updates and changed mods are picked up. hy-scheduler runs in the background: it refreshes the login, and with RESTART_MODE it runs hy-restart.

docker stop. A running server saves the world first. During steps 1 to 5 the container stops at once. During the world check it waits for a clean stop.

Crash or exit. The server exited without a stop or a restart. The container's restart policy decides what happens next.
